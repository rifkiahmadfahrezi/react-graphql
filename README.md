# Simple todo list

Practice CRUD operation with Graphql in React, utilize Shadcn UI, Tanstack Query and json-graphql-server.

## Local installation

1. clone repo `git clone https://github.com/rifkiahmadfahrezi/react-graphql.git`
2. install dependecies `pnpm install`
3. run `pnpm run dev:all`

Graphql server run on port 8080
Frontend run on port 3000
